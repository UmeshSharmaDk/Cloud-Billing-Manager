Build a modern cloud-based GST Billing & Inventory Management Platform for Indian businesses.
The platform must support multi-user SaaS architecture with Admin Panel and User Panel.

The application should be production-ready, scalable, secure, mobile responsive, and compliant with Indian GST laws and invoicing standards.

Deployment: Docker + Nginx + AWS/VPS
